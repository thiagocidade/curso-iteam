# Atividades das Aulas

Este repositório reúne atividades práticas desenvolvidas durante as aulas de HTML e CSS.

## Conteúdos estudados

### Aulas 1 e 2 — HTML

- Estrutura básica de uma página HTML.
- Títulos, parágrafos, links, listas e navegação entre páginas.
- Organização de conteúdo com `div` e `span`.
- Tags semânticas, como `header`, `main`, `article`, `aside` e `footer`.
- Criação de tabelas.
- Formulários com campos de texto, e-mail, número, opções e seleção.

### Aula 3 — CSS

- Aplicação de estilos em páginas HTML.
- Seletores por tag, classe, identificador e atributo.
- Cores, fontes, tamanhos, margens, espaçamentos e bordas.
- Arredondamento de elementos e controle de exibição.
- Efeitos de interação com `:hover` e conteúdo adicional com `::after`.

### Aula 4 — Flexbox e responsividade

- Organização de elementos com Flexbox.
- Alinhamento, espaçamento e direção dos itens na página.
- Uso de `box-sizing` para controlar o tamanho dos elementos.
- Adaptação de estilos para diferentes tamanhos de tela com `@media`.

### Aula 5 — JavaScript

- Introdução ao JavaScript dentro de uma página HTML.
- Criação de variáveis e realização de operações matemáticas.
- Exibição de resultados com `alert`.

### Projeto Linktree

- Desenvolvimento de uma página de links pessoais inspirada no Linktree.
- Uso de imagem de perfil, links principais e ícones de redes sociais.
- Estilização final com Flexbox, gradiente, tipografia, botões e efeitos de interação.

## Como visualizar

Abra o arquivo `index.html` na raiz do projeto e escolha a aula desejada.
